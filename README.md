## 🌟 專題特色與功能亮點

1. **🏰 百款館藏桌遊圖鑑 (Game Showcase)**
   - 預設 12 款精選桌遊（派對同樂、心機陣營、策略燒腦、雙人對決、闔家歡樂、冒險合作）。
   - 支援依「關鍵字搜尋」、「遊戲類型」、「遊玩人數（2人/3-4人/5-6人/7+人）」、「難易度」即時複合篩選。
   - 遊戲詳情彈窗：包含遊戲背景、核心機制、遊玩時長、租借費用與推薦年齡。

2. **🗺️ 冒險者公會・店內桌位平面預約系統 (Interactive Table Booking)**
   - 視覺化「像素店內平面配置圖」：可點選雙人座、四人方桌、和室大包廂、VIP 沉浸劇本包廂。
   - 點擊平面圖自動帶入桌號、費率與特色說明。
   - 預約契約表單：日期、時段、姓名、手機、人數、飲料零食補給套裝加選。
   - 預約完成後即時生成像素風格「冒險者預約憑證卡」，並支援一鍵列印/存檔。

3. **⚙️ 後台館藏與預約資料管理中心 (Full CRUD - 評分加分項目！)**
   - **完全符合期末評分標準加分項**：「提供後台或管理介面，可實際示範 CRUD（新增、編輯、刪除資料）且畫面/資料有更新保存，可不做登入。」
   - **桌遊管理 (CRUD)**：
     - **Create**：新增館藏桌遊（名稱、Emoji 圖示、類別、支援人數、難易度、外借費用、介紹與標籤）。
     - **Read**：後台即時清單與搜尋比對。
     - **Update**：編輯任何已有桌遊的所有屬性。
     - **Delete**：安全防呆刪除確認。
   - **預約管理 (CRUD)**：
     - 即時檢視所有顧客預約清單。
     - 一鍵切換預約狀態（⏳待確認 / ✅已預約 / 🎮已入座 / 🏆已完成 / ❌取消）。
     - 支援個別刪除與一鍵清空。
   - **資料保存 (Data Persistence)**：
     - 使用前端 `localStorage` 自動同步儲存，重新整理網頁或重開瀏覽器資料不遺失。
     - **備份與評分工具**：提供「📥 匯出當前資料 (JSON 下載)」、「📤 匯入 JSON 資料」與「🔄 還原為官方預設資料」。

4. **🎲 冒險者實用工具箱 (Mini-Tools)**
   - **命運像素骰子 (Dice Roller)**：支援 D6、D20、雙骰 (2D6) 與像素硬幣翻轉，帶有旋轉搖動動畫。
   - **「今天玩什麼？」命運之輪 (Game Recommender)**：依當前聚會人數自動從館藏中隨機召喚合適遊戲。

5. **🔊 8-Bit 原生合成復古音效 (Web Audio API)**
   - 無需下載外部大型音檔，使用原生 Web Audio API 合成金幣聲 (Coin Chime)、按鈕音 (Blip)、擲骰滾動聲 (Rumble)、成功號角 (Tada Chime) 與刪除音。
   - 右上角隨時可一鍵切換靜音 / 開啟音效。

## 🚀 如何在本機試用與操作

本專案採現代標準前端架構（HTML5 + CSS3 + Vanilla JavaScript），具有**零依賴、無須建置編譯、開箱即用**的優勢：

### 方式 1：直接開啟（最簡單）
1. 在檔案總管中進入本專案資料夾：  
   `C:\Users\User\.gemini\antigravity\scratch\pixel-boardgame-cafe`
2. 直接雙擊 `index.html`，即可在任何瀏覽器（Chrome、Edge、Safari 等）中立即運行試用！

### 方式 2：使用本機伺服器預覽
若您有安裝 VS Code，可使用 **Live Server** 延伸模組；或在終端機輸入：
```bash
npx serve .
# 或使用 Python
python -m http.server 8080
```

## 🌐 如何部署到 GitHub 與 Vercel（期末加分 10 分）

### 步驟 A：建立 GitHub 公開專案庫
1. 由組員登入 [GitHub](https://github.com)，點擊右上角 **New repository**。
2. Repository name 填寫例如：`pixel-boardgame-cafe`。
3. 務必勾選 **Public**（公開），點擊 **Create repository**。
4. 將本專案資料夾內的所有檔案（`index.html`、`style.css`、`app.js`、`vercel.json`、`README.md`）上傳至該專案庫（可直接透過 GitHub 網頁上方的 **Add file -> Upload files** 拖曳上傳，或使用 Git 指令 push）。

### 步驟 B：在 Vercel 進行免費一鍵上線部署
1. 登入 [Vercel](https://vercel.com)。
2. 點擊 **Add New... -> Project**，連結剛才建立的 GitHub 專案庫。
3. Framework Preset 選擇 **Other**（或預設），根目錄為 `./`。
4. 點擊 **Deploy**！
5. 數十秒後即可取得公開 HTTPS 網址（例如：`https://pixel-boardgame-cafe.vercel.app`），將此網址填入期末專題草稿中！

### 步驟 C：每位組員貢獻一筆 Commit
- 指南規定：「每一位組員都必須用自己的 GitHub 帳號至少 commit 並 push 一筆貢獻」。
- 組員可於 GitHub 專案庫網頁中點擊 `README.md` 或 `app.js` 右上角的鉛筆圖示進行編輯（例如補充心得、增加桌遊資料或優化備註），填寫 Commit message 後送出，即可算作個人 GitHub 貢獻！
