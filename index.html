🎮 專案理念與像素風格設計

選題動機： 現代桌遊包羅萬象，但很多新手走進桌遊店往往面臨「遊戲太多不知怎麼挑」、「現場客滿沒位子」或「規則看不懂」的困擾。

風格與視覺決策： 我們選用 8-Bit / 16-Bit 復古 RPG 冒險者公會 的像素美學作為視覺核心。將桌遊店包裝成「冒險者集結所」，讓每一次選桌遊、預約包廂都像是在 RPG 遊戲中接任務與挑選裝備一樣趣味生動！

核心特色： 結合了「像素店內選位」、「百款館藏圖鑑」、「後台 CRUD 管理」、「隨機遊戲命運之輪」與「8-Bit 原生 Web Audio 復古音效」，兼具實用性、娛樂性與技術完整度。

📝 期末專題實際改善紀錄（指南規定至少三處）

改善紀錄 #1：視覺沉浸與風格統一

原問題： 初版一般網頁排版較單調，缺乏「桌遊店」探索與遊戲的氛圍感。

改了什麼： 導入 8-bit / 16-bit 像素 RPG 視覺系統（復古雙層像素陰影邊框、DotGothic 像素字體、NPC 店長對話框與 Web Audio 原生合成像素音效）。

怎麼確認驗證： 經組員跨瀏覽器測試，按鈕點擊有即時 8-bit 音效回饋，視覺層次分明且不需加載龐大外部音訊檔。

改善紀錄 #2：後台資料持久化與 CRUD 完整度

原問題： 原先在前端新增或編輯桌遊與預約時，重新整理頁面後資料就會遺失，無法滿足期末評分「資料有更新保存」的加分項目。

改了什麼： 實作 LocalStorage 自動同步儲存架構，並加入「匯出 JSON / 匯入 JSON」與「一鍵恢復預設值」功能。

怎麼確認驗證： 於後台新增「璀璨寶石：城市擴充」並修改預約單狀態為「已完成」，重新整理瀏覽器或換分頁，所有新增與修改內容皆完整保留。

改善紀錄 #3：預約選位直覺化（像素店內平面圖）

原問題： 一般預約表單只有文字下拉選單，顧客無法得知雙人桌、大長桌或和室包廂在店內的相對位置與環境特色。

改了什麼： 設計互動式「像素平面配置圖」，顧客點選平面圖上的桌位節點，右側預約單會同步自動帶入桌號、桌型與費率計價說明。

怎麼確認驗證： 點擊 VIP1「巨龍包廂」，預約表單即時聯動更新；送出預約後產生像素風「冒險者預約憑證卡」，可於後台即時查驗。
